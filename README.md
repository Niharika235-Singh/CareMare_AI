# CareMate AI 🩺

CareMate AI is an AI-based healthcare project focused on disease-related analysis using machine learning and deep learning techniques.

## 📌 Project Overview

This project brings together application code, model-related components, training notebooks, and supporting resources in one repository. It is designed to explore how AI techniques can support healthcare-related analysis.

## ✨ Project Components

- **Application:** `app.py`
- **Source Code:** `src/`
- **Disease Model Components:** `Best_Disease_Model/`
- **Results:** `results/`
- **Model File:** `best_model_using_lstm.pth`
- **Training Notebooks:** Jupyter notebooks for model training and evaluation
- **Dependencies:** `requirements.txt`

## 🛠️ Technologies

The project includes Python code, Jupyter notebooks, and an LSTM model file. Refer to the source code and `requirements.txt` for the complete technology and library details.

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone YOUR_REPOSITORY_URL
cd CareMate-AI
```

Replace `YOUR_REPOSITORY_URL` with the URL of this GitHub repository.

### 2. Set up Python

Create and activate a virtual environment if needed.

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

### 4. Run the application

The application entry point is `app.py`. Check its imports and configuration to determine the required launch command and any additional setup before running it.

```bash
python app.py
```

## 🧪 Model Training and Evaluation

The repository includes notebooks for model training and evaluation. Open them in Jupyter Notebook or Google Colab to inspect the workflow and reproduce experiments where the required data and dependencies are available.
